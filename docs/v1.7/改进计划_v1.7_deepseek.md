## 0. 全局守则（每次开工前必读，两执行者通用）

1. **一次只做一张卡**。开工只读：本卡、TDD 被引章节、本卡"先读"文件。**不要**通读仓库。
2. 改动范围 = "只许改"清单。想到别的改动 → 写入卡尾"移交事项"，**不许顺手改**。
3. 接口与 TDD 冲突 → **停下，报告冲突**，不许自己二选一。（行号漂移除外，见 §-1.3）
4. 判据/门限一个字不动（构图门 0.70、门①–⑩、top_k=15 等）。
5. **新检测规则一律 warning 级起步**（红线 R-V）：R020–R025 只许告警。
6. `contracts/`、`utils/`、`overlay/geometry.py`、`tools/check_assistant_assets.py`、`cinema/camera_narration.py`、`layer8_delivery/target_advisor.py` **不许 import bpy**。
7. `.ps1` ASCII-only；调 Blender 的 `.ps1` 保持 `$ErrorActionPreference = 'Continue'`，看 `$LASTEXITCODE`。
8. 每卡完成后跑 `python -m pytest`；红了先修自己的卡，**不许** skip/xfail 盖红。
9. 改了 `contracts/config.py` → 必须跑 `python tools/gen_specs.py`。
10. key 明文不进：YAML、trace、审计、HTTP 响应、git（掩码规则 TDD §4.3）。
11. 每卡结尾 commit：`v1.7 <卡号>: <一句话>`，commit 前全绿。
12. 配置错误码只用 **CFG_17x** 段（分配表 TDD §4.1）；021–023/215–217 已占（2026-10-10 实读：CFG_023 在 `config.py:498`，"顺延到 215–217"注释在 :500）。
13. R-痛点数字照抄时必须注来源（`# src: R-痛点 P7`）。
14. YAML 只许用 `contracts/config.py::parse_yaml`（:807）/`dump_yaml`（:822）；不引第二份解析器。
15. **文件互斥**：同一文件的卡严格按 §0.2 互斥表串行；不同文件的卡可并行；每卡 commit 后另一方同步工作区再开新卡。
16. **冻结基线**：J 阶段每张新规则卡必须跑三份冻结工程、把新规则读数基线写进 `docs/evidence/<date>-v17-*/`；golden 对拍只允许"新增行"级差异，diff 摘要写进 commit message；**不许拧阈值消读数**。
17. **台账先行**（v1.7.5 新增）：开工先在 `v1.7/PROGRESS.md` 把卡标"进行中"再动手；收尾改"完成/待复核"。
18. **F1 哨兵类型归属**（v1.7.5 新增，防依赖反向）：`SkippedFinding` 定义在 **`contracts/audit.py`**（它是个 DTO），`rule_checker.py` import 它——反过来会让 contracts 依赖 layer3，撞依赖红线。

## 0.3 协作操作协议（v1.7.5 新增：分工的机械落地）

1. **同步**：每卡 commit 后另一方 `git pull`（共享工作区则直接可见）再开新卡；开卡前 `git log --oneline -5` 确认对方最新落点。
