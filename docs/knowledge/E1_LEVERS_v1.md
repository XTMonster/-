**两个关键事实**：

1. **1,280 个三元组的平均命中 = (547+2×376+3×49)/1280 = 1.1297 ⇒ /3 = 0.3766。**
   而"逐查询挑最好"是 0.7448 ⇒ **同一堆候选里，选不选得动，差距是 0.3766 vs 0.7448**。
   这就是 GPT-6A 说"转向选择器"的算术依据。
2. **49/1280 = 3.8% 的三元组是 3/3**；64 条查询里 **22 条**至少存在一个 3/3 组合。
   ⇒ 上限不是"没有好组"，而是"**好组稀且没有不看得分就能认出它的办法**"。

## 2. 三根杠杆（按"能不能查/值不值得"排序）

### 杠杆 A：**换更好的去标签候选池**（唯一还没试过的正向工程）

* 现在这 20 组的池子是**按标签分取 top-6**⇒**池子本身用了标签**，选择器不许看标签，
  所以池子必须重建，而**重建后的 oracle 从来没人量过**（`work/_probe_labelfree_pool.py`
  正在试点：`index.retrieve(query, top_k=6)` 的原始名次，全组合 20 组，同面板 C=3 判）。
* **已入库的"还没在重排位上试过"的证据**：`docs/knowledge/OPEN_PROBLEMS.md` **P3**——
  本地 `bge-small-zh` 做重排是**负结果**（0.0938/0.0833，比不重排 0.2188 还差），
  但 **D3 实测过"同一路由换云端嵌入器 E1 提高约 5.6 倍"**，而用户**已买下智谱
  `embedding-3` 资源包**（`docs/knowledge/ADJUDICATIONS_v4.md`）。
  ⇒ **"云端嵌入重排"这个位置是空的**，而它天然**不看判分**（合法作为去标签池的构造器）。
* 判据：去标签池的 oracle 一旦 **< 135/192**，**任何选择器都不可能过线** ⇒ 必须回 GPT-6A
  带实测重定门槛或改池子；**≥135** 则选择器这条线才成立。

### 杠杆 B：**训选择器**（裁定直接要求的那条）
