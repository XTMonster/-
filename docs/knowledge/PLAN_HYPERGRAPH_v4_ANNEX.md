## 0. 术语与真源（覆盖正文 §1 术语表里相关条目）

| 术语 | 定义（本附件口径） |
|---|---|
| **轮记录文件** | 每跑一轮 E1 就落一份 `round.<route>.<n>.json` 到证据目录，字段＝`seed`／行清单摘要／评委配置摘要／语料 manifest 摘要／超图 manifest 摘要／终态。**执行器是唯一写入方**，检查器只读。 |
| **行清单文件** | 每个阶段一份（行号＋内容摘要＋sha256）。正文里一切"评测集＝N 行"的写法**作废**，一律改成"当前实际使用的行清单文件"。 |
| **噪声带 R** | 参与比较的那些臂的**同臂极差的最大值**（不是写死的 0.02，也不是半宽）。`|Δ| > R` 才算量到差别；否则终态是 `inconclusive`，**不是"相等"**。 |
| **有效轮** | 一轮读数计入统计，当且仅当：两臂成对（同一 seed／行清单／评委配置／知识库构建身份）＋ 降级计数＝0 ＋ 读数与计数取自**同一生产者**。 |
| **作废事件** | 两个**可区分**的终态码：`invalid_parse_fault`（解析失败）与 `invalid_empty_intersection`（合法空交集）。它们只写进轮记录文件，**没有**第二条入账通道。 |
