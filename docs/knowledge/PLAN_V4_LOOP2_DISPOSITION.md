## 处置表与修订条目

第一原理（处置这 37 条时用到的五条，每条都决定了'改成什么'的形状）：
① 判据与仪器分离。判据（红线 0.70、护栏 0.30、E1 分子分母定义）是联合会诊的立法产物（先例：066d85d 'S2 立法裁决（联合会诊判 A）'），修订计划无权改；仪器（怎么重复、分母怎么算、措辞怎么写）是工程，当场可改。37 条里绝大多数打的是仪器规格而非判据本身——所以能改的痛快改，碰判据的一律进裁决队列。
② 显著性线不得低于被测噪声。0.02 < 0.0208 < 0.0365：低于同臂极差的线不是阈值，是掷硬币。阈值必须从'同一配置、写死次数 N'的重复测量推导，且推导程序本身写进计划。
③ 结论强度 ≤ 证据强度。'物理上没有 embedding 端点'是全称命题，'当前 key 三路径探测返回某码'是单例观察；把后者说成前者是免费透支信用。
④ 手抄必漂。git 史有书面实锤（53d3e3f 'sidecar 手抄的那份已经漂'）；因此读数、探测结果、产物清单一律引用权威存档（trace 生产者、探测存档、manifest），正文不转写。
⑤ 视野问题用参数解决，不用代码解决。C5③（检查器零改动）与 C7（影子路径 knowledge_v4/）的冲突靠'换入参不换编码'化解，并用 sentinel 探针证明真的换了。
为什么在本项目成立：每条原理都对应 bundle 内可指认的证据——0.02 与 4/192、7/192 的数值关系是算术；53d3e3f 的提交信息是漂移前科的书面证据；hypergraph.py 第 35–43 行的 schema_fingerprint docstring 与 066d85d '三组"决定收不收"的闭集进指纹'证明本项目已有'闭集变更必须令缓存换代'的机制，B.8 直接复用它而不是新发明制度。
怎么做——以下 8 段为可直接粘贴进计划的修订正文（与处置表 F 编号互引）：
【B.1】C6 · E1 读数纪律（替换原'|ΔE1| < 0.02 标 inconclusive'整段）
(1) 重复协议：每臂（hybrid／lexical）在同一配置下独立重复 N 次。N 与评测集规模写死于本条：N＝8（协议常数，裁决前可复议），评测集＝192 行；每次重复的 seed 清单随轮存档；测量开始后不得增删次数。历史读数（同臂极差 hybrid 4/192＝0.0208、lexical 7/192＝0.0365）未绑定写死的 N，一律降级为背景观察：不进阈值推导、不进方向性结论。
(2) 有效轮定义：一轮读数计入统计，当且仅当同时满足——a. 两臂成对：同轮 hybrid 与 lexical 用同一 seed、同一评测集版本、同一评委配置；b. 降级计数＝0：该轮任一降级路径被触发即整轮作废（不参与统计），作废原因记入权威 trace；c. 单一生产者：读数与降级计数只取自 trace 的同一生产者（53d3e3f 修的那条链），sidecar 手抄件不作为数据源。'四次单跑'类非成对数据不得用于任何方向性陈述。
(3) 噪声带推导与判定：噪声带 R ＝ max(hybrid 的 N 次同臂最大极差, lexical 的 N 次同臂最大极差)，以'行数/192'与十进制小数同时记录（极差是全幅，禁写 ±）。判定：|ΔE1| < R → 本轮标 inconclusive，禁止陈述两臂方向；|ΔE1| ≥ R 才允许方向性陈述。若 R ≥ 两臂历史差值，结论段必须写明'现有重数下 E1 对两臂之差不具分辨力'并给出按本条补测的路径，不得只写'标 inconclusive'。
(4) 阈值地位：本条只定义推导程序；R 的具体数值及其是否作为验收门限、与红线 0.70 的关系，单列待裁决（#R1）。裁决前，inconclusive 只是读数标注，不改变任何既有门限。
【B.2】C8 · rejects 率（替换原 rejects 率整段）
(1) 分母的精确公式：rejects 率 ＝ R / (E + R)，其中 E＝hypergraph.edges.jsonl 的行数（收下的边），R＝hypergraph.rejects.jsonl 的行数（判'不收'的边）；分母 E＋R 即'进入收/不收判定的全部候选边'。任一文件缺失 → 本指标记'不可计算'，禁止以 0 代入。
(2) 首跑基线：B0 ＝ 冻结 commit 53d3e3f 上、同语料、同配置、降级计数＝0 的首次构建所得 rejects 率；E、R、两文件 sha256、B0 一并写入 hypergraph.manifest.json（构建期留痕，与 MANIFEST_FILE 约定同源）。
(3) 阈值来源（如实声明）：0.30 是预设工程护栏，不是数据校准的产物；B0 与后续分布作为校准证据积累。0.30 是否随校准调整，单列待裁决（#R2）；裁决前按原值执行，且 B0 > 0.30 时护栏空转，必须触发上报，不得静默通过。
(4) 措辞修正：'hypergraph.edges.jsonl 内零违例'是构造性结果（判不收者按定义不入主产物），只作事实陈述，不作为质量证据；监控对象是 rejects 率及其随语料变更的漂移。
