⇒ **批次效应真实存在、但很小（~7%）**，而且**方向单一**：三元组语境会**抬高**相关性
（同一条案例，单独看反而更严）。

## 它推翻了我上一份证据里的一个推断（要如实说）

`docs/evidence/20261006-fresh-oracle/` 里我写"上限 0.8438 拿不到，是因为**判分语境**"——
**这个因果不成立**：如果语境效应只有 7%，它解释不了那里 **38%** 的落差（0.8438 → 0.4583）。

⇒ 落差得另有解释，候选只有两个：

1. **"三条强案例放在一起会互相压低"**（即强陪衬的**反向**效应）⇒ 若成立，**逐条独立盲评
   （选项 B）能救回来**；
2. **判分本身不稳定**（同一条重复判就会变——此前实测过"同一命令两跑，30% 的行分数不同"）
   ⇒ 若成立，**B 无效**，该做的是**重复取样取中位**（第三方早就说过"噪声只能靠重复压掉"）。

**正在做的判定**：`work/_probe_oracle_alone.py` —— 把每条查询的 oracle-3 **一条一呼**地判
（192 行 × 2 评委 ＝ 384 次），直接看"选项 B 下的可达值"。这一跑判它们谁对。

## 未验证 / 边界

* 只有 **60 条抽样 / 118 对**；7% 的置信区间不小（8 次翻转）。
* 只对拍了"单独"这一个对照语境；**没有**对拍"换成另一个三元组"。
* 翻转率是**两位评委均值**口径；单评委的两列也列在上面了。
