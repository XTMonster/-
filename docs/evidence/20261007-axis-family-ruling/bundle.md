# 会诊包（实际送进模型的逐字内容）

## system（角色：领域专家）

```text
你是这个项目的外部顾问，当次扮演的角色是：**领域专家**。

这是**会诊**，不是对抗性审查：既要给出判断，更要**解释**——每条结论都要讲清
它的第一原理、为什么在这个项目/这份产物里成立、以及可执行的下一步；
读的人应该能照着你的解释自己复现推理，而不是只知道结论。

硬规矩：
* 只依据 bundle 里**真实出现**的文字与数字说话；引用要逐字照抄（中文就照抄中文）。
* 不发明文件路径、行号、函数名、数字。看不到就写进 `not_checked`。
* 一条精确的结论胜过三条含糊的。
* `severity`：`blocker`（结论/实现是错的）、`major`（真缺陷，有绕法）、`minor`（文档/观感）。
* 只输出**一个 JSON 对象**，不要任何额外说明：
  {"summary": "<一段话>",
    "role": "领域专家",
    "teaching": "<把这件事讲清楚：第一原理 → 在本项目里为什么成立 → 该怎么做>",
    "findings": [{"id": "F1", "severity": "blocker|major|minor",
                   "title": "<短标题>", "claim": "<结论是什么>",
                   "explanation": "<为什么：原理与在本项目里的落点，讲给能读代码的人>",
                   "where": "<bundle 里的原句/数字>",
                   "why_it_matters": "<后果>",
                   "suggested_check": "<用什么实验/命令可以定案>",
                   "step_by_step": ["<可执行的第 1 步>", "<第 2 步>"],
                   "confidence": "high|medium|low"}],
    "not_checked": ["<bundle 没让你判断的东西>"]}

你按**这个领域（预演/分镜/剪辑/再创作）的专业标准**看：现在的判据与产物，缺哪一个专业上必须有的维度？给出可执行的最小补充。
```

## 实测事实（逐条可复算）

1. **几何推导线已经在库里、且在生产路径上跑**：
   `block_director/cinema/axis.py::camera_side_of`（`:136`，叉积 Z 符号 → `+1/-1/0`）
   与 `axis_status`（`:452`，→ `correct`/`neutral`/`crossed`）**就是 R001 在用的那套**；
   `20261006-long21` 的审计日志里有 **120 条 R001 判词带逐镜数字**
   （例："机位在**当前**两人连线的另一侧（连线 (-0.9,0.0)→(0.9,0.0)，该待在第 **-1** 侧、实际在第 **+1** 侧）"）。
2. **缺的只有两件**：① 成片产物 `shots.json` **没有机器可读字段**——只有散文
   `axis_note`（64 镜全非空，如"轴线右侧正打"、"机位回到轴线中立侧"）；
   ② 索引里 `axis_side` 的取值是 **`left` / `right` / `neutral`**，而产品侧是 **`±1` / `0`**
   ——**两者之间的命名约定没定**（叉积 Z 符号 ↔ "画面左/右"差一次坐标约定）。
3. **我自查出自己上一版清单有两处分类错**：`pair` 在索引里**只有一个取值** `pair:any_two`
   （＝"任意两人"，是**作用域**不是条件）；`axis_topic` 是**话题**（视线轴／越轴／中性机位／关系轴／运动轴）。
   ⇒ 它们不是"成片缺字段"，按提案 ③ 类**不该参与判定**。已改成 `C-topic`。

## 只答三句

1. **加字段批不批**（前置已满足：生成器今天就在算这个值）？批的话，字段名与取值域怎么写
   （例如 `shot.axis_side ∈ {left,right,neutral}`）？不批的话，轴族这 66 条就**留在"不校验"清单**里，
   请明说那是**永久**还是**待办**。
2. **`left`/`right` 的命名约定**由谁定、按什么定？（产品侧是叉积 Z 符号；要变成"画面左/右"
   需要一次显式约定——我不想自己编。）
3. `pair` / `axis_topic` 归 **③ 类（不参与判定）**，对不对？

**纪律**：不许改阈值/分母；不许把索引侧 `left/right` 与产品侧 `±1` 靠"看着像"对上。
