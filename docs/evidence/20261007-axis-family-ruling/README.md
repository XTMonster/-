## 二、校准**已做**，结果是"**不一致**"（`axis_convention_calibration.json`）

```powershell
python work/_probe_axis_convention.py

#  "cross_tab": {"+1 | left": 5, "+1 | mixed": 2, "+1 | other": 8, "+1 | right": 1,

```

**同一个符号 `+1` 同时和"轴线右侧"与"轴线左侧"两种措辞同镜出现**，逐条看更清楚：

| 镜 | R001 的实际侧 | `axis_note` 原话 |
|---|---|---|
| `shot_027` | **+1** | 轴线**右侧**正打，视线朝画面左 |
| `shot_030` | **+1** | 轴线**右侧**特写 |
| `shot_031` | **+1** | 轴线**左侧**特写，与镜号 30 反向 |
| `shot_036` | **+1** | 轴线**左侧**反打，视线朝画面右 |
| `shot_047` | **−1** | 轴线**左侧**特写，与镜号 46 反向 |
| `shot_049` | **−1** | 建立轴线：米迦尔在左、伊恩将入画于右，机位置于轴线**中立**侧 |

**根因（这就是"约定"缺的那一层）**：`camera_side_of` 的 ±1 是**相对"有序 pair"的叉积符号**，
而那个 pair 的次序取自 `axis.py:430` 的 `left_label`/`right_label`——**两人在画面里互换时它会翻**。
所以"同一符号 ↔ 相反措辞"不是笔误，是**两套参考系**（world 叉积 vs 画面左右）。
**散文 `axis_note` 里还混着"角色站位"（米迦尔在左）与"机位所在侧"两种意思**，
所以它**不能**当校准基准。

⇒ 按裁定，**不一致**这一支的动作是：**弃 `left/right`，索引改用符号域**——
那是**知识侧**的改动（换取值域＝换代），**本轮不动**，列为下一步。
