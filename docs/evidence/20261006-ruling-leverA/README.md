# 一次**没有发出去**的会诊包（`bundle.md` 从未送给任何模型）

日期 2026-10-06。

## 这是什么

`bundle.md` ＋ `bundle.manifest.json` 是 `tools/glm_consult.py` 生成的**逐字会诊包**。
这一次调用**以 `exit=1` 结束**，`stderr` 只有一行：

```
未知角色 '棰嗗煙璁茶В'；可用：实现顾问, 性能与鲁棒, 接口与契约, 测试与验收, 红队反方, 规格一致性, 领域专家, 领域讲解
```

**根因**：角色名 `领域讲解` 是**中文**，调用方走的是 **Windows PowerShell 5.1**（`powershell.exe`，
控制台代码页 GBK），中文参数在**命令行边界**上就被按 GBK 解码，到了 Python 手里已是 `棰嗗煙璁茶В`；
而 `glm_consult` 只认**8 个具名角色**，于是**当场拒收**。
⇒ **这个包从来没送给任何模型，所以本目录里没有判词**（`bundle.md` 里的 `system` 段只是"本会送出去的内容"）。

## 为什么留着它（而不是删掉）

它是"**中文参数不要走 PowerShell 5.1 命令行**"这条教训的**现场**：本仓已经踩过两次
（另一次是主线自己给 `glm_consult` 传角色名，同样报"未知角色"）。
可靠的写法有两条，**都实测过**：

1. **在 pwsh 7 里调用**（UTF-8 命令行）——主线用
   `--roles 测试与验收,红队反方` 一次就通（见 `docs/evidence/20261006-e1-gate-glm/`）；
2. 把**中文只放在文件里**（`--question <路径>`、`--source <路径>`），命令行上只留 ASCII
   （这条对 `.ps1` 也成立：本仓规定 `.ps1` **必须 ASCII-only**，所以不要指望用包装脚本塞中文）。

## 第二次尝试：**发出去了，又被主线自己掐掉**（如实记）

同一天同一问在 pwsh 7 里重发过一次（`--roles 领域讲解,实现顾问 --partner glm --level max`，
pid 56504，22:41:16 起）。它**通过了**角色校验并写出了本目录的 `bundle.md`（18,468 字节），
但**跑了 21 分钟仍无产物**，被主线在 23:03 掐掉。两个理由，**都写在这里而不是只留在终端**：

1. **包太大**：本仓实测的 GLM 包线是 **~3,000 字符**，而这份 bundle 是 **18.4 KB**
   （因为带了两份 README 的 `--context`）。超出包线的调用正是本仓已经踩过两次的
   "思考吃满预算 ⇒ 空正文/超时"形状 ⇒ **期望值就是拿不回可解析的判词**；
2. **同一问已经被答过**：`docs/evidence/20261006-e1-gate-glm/`（22:53:48）已经从
   GLM-5.3 拿到"E1 在现行判据下**不可达** ⇒ 走 (a) 如实记红"的裁定；再花一轮 GLM
   只会挡住主线后面那条 **3.5～7 小时**的终局证据跑。

⇒ 本目录现在的身份是"**两次失败/中止的会诊包**"，**不是判词**；判词在 `…-e1-gate-glm/`。

## 为什么**不**再重发这一问

它要问的是"**杠杆 A（云端嵌入重排）值不值得真判**"。这个问题已经被**实测**回答了，
而且答案比咨询更硬（见 `../20261006-e1-cloud-embed/README.md`）：

* 上界位：proxy 上三面最好的配置只比"检索原序"高 **+0.0105**（0.1667 vs 0.1562）；
* 交付位：真判分 `k20 = 0.1667`、`k50 = 0.1146`，**都低于现役 0.1771**。

⇒ **测量胜过咨询**：这一问不必再花一次会诊（也就省掉 GLM-5.3 一轮 5～20 分钟）。

## 复现（正确写法）

```powershell
# 必须在 pwsh 7（或先把控制台代码页切成 65001）里跑，否则中文角色名会在命令行边界被 GBK 吃掉
python tools/glm_consult.py --roles 领域讲解 --question work\_q_ruling_leverA.md `
    --question-only --no-status --out work\_ruling_leverA_ok
```

（`--question` 给**文件路径**；`--roles` 必须用**那 8 个具名角色之一**。本仓已经两次栽在这条上。）
