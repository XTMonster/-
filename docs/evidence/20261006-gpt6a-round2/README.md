### `answers/a_metric.md`（sha256 前 12 `04e37cc718c8`）——问题：这条质量度量本身可信吗？

**通道事实**：18:35 发出、**18:39:54 拿到正文**（857 B）。

它的两句（**逐字见原件**）：

1. **"强支持，非因果定论。"** 最该推翻的假设是「**相关标签与同伴无关、可跨批复用**」。
   7% 的定向翻转 ＋ 同例 0.4583→0.1458 支持呈现效应；**但 30% 的分数漂移仍须排除**
   （否则"呈现效应"与"评委噪声"两个解释分不开）。它给的判据：**同例随机交叉、重复盲评**，
   **呈现方式之间的配对差的置信区间排除 0** ⇒ 才算否定该假设。
2. **"结算交付情境，不冒充固有相关性。"** 不要重定义"固有相关性"，而是**结算一次交付情境**：
   固定 Q 个**实际三元组与顺序**、原判据、**两评委的版本/提示**，**预登记 R 轮复评与区间算法**：

   ```
   Ê1 = (1/R) Σ_r (1/3Q) Σ_q Σ_i 1{ (s_{1qir}+s_{2qir})/2 >= 4 }
   ```

   先判相关再平均，每轮分母仍 `3Q`；**通过要单侧 95% 置信下界 ≥ 0.70**。
   并明确：**复评与置信结算须验收方显式批准**，不能冒充原来的单轮结算；
   若禁止补充协议，就**只能原样报告，不能自行改尺**。
