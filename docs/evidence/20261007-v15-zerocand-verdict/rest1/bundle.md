```text
# 本次要审的问题

# 只做一件事：给 12 条"**无卡可佐证**"的边槽位做**出处裁决**

背景（一句话）：这套镜头知识索引里，每条边的每个成员都该有**来源卡**；判"有没有"
的口径是**取值原文**（surface）能不能在**这条边自己的来源卡正文**里找到。下面这些
槽位连**全库任何卡**的正文里都找不到该取值——所以机械补卡补不了，只能裁定它们
该不该留着。

**判法（只看下面给的证据）**：

* `keep`：取值本身站得住。卡里没有这个串有两种良性成因——① 它是**闭集词元**
  （引擎/schema 用的标识符，中文语料卡构造上不会写出这种串）；② 卡在讲**对的**
  主题，只是没有逐字写出这个取值（蕴含未写出）。两种都**不是**"挂错卡"。
* `wrong_card`：这条边的来源卡**主题**与这个取值不是一回事（例如拿"三脚架调平"的卡
  去挂 `composition_rule:balance`）——建议把**这个成员**从这条边摘掉。
* `wrong_value`：卡在讲对的主题，但**取值本身**抄错/编错——建议把**这个成员**摘掉。

拿不准就判 `keep`，但把理由写清（宁可漏报，不要乱扣帽子）。
**只输出一个 JSON 数组**，长度 = 12，每条形如
`{"i": 1, "verdict": "keep"|"wrong_card"|"wrong_value", "why": "<不超过 25 字>"}`。
不要任何额外说明。
```
