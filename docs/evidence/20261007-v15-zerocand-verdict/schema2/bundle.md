背景（一句话）：这套镜头知识索引里，每条边的每个成员都该有**来源卡**；判"有没有"

  去挂 `composition_rule:balance`）——建议把**这个成员**从这条边摘掉。
* `wrong_value`：卡在讲对的主题，但**取值本身**抄错/编错——建议把**这个成员**摘掉。

拿不准就判 `keep`，但把理由写清（宁可漏报，不要乱扣帽子）。
**只输出一个 JSON 数组**，长度 = 12，每条形如
`{"i": 1, "verdict": "keep"|"wrong_card"|"wrong_value", "why": "<不超过 25 字>"}`。
