## 这说明什么

1. **"意图可表达"比"提示词更严厉"重要**：`side` 与 `amount` 两处契约一补上，
   模型说的和引擎做的就对上了；层状态那处更是纯实现缺陷（角色被瞬移到原点，
   是构图整片判红的根因之一）。
2. **下一条主要矛盾换人了**：R003 从 322 掉到 38，而 **R001（180° 轴线）升到 79**——
   机位现在真的按模型要的角度摆，于是"摆错一侧"第一次真的发生了。
   这是**下一个**要修的方向（轴线约束要么进 B1 的提示与校验、要么由求解器
   在摆位时按轴线夹住），而不是继续在动作时间轴上打转。
3. 剩下的 COMPOSITION 120 里，仍有相当一部分来自"主体偏离三分线交点"这条
   *评分模型*口径（`rule_of_thirds` 要求交点、而电影取景常用三分**线**）——
   该不该动它属于口径裁决（见 `ACCEPTANCE_STATUS.md` §五十五/§五十六）。
