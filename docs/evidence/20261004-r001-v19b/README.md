## 会诊说了什么（逐条回仓库复核后的裁决）

### F1（**成立**）：`bridged` 是**存在性**判定，与漂移量级脱钩

它给的反例可复现：镜头里两人同框、连线转过 **6°**（`visible=True`），此后在一次
**不同框**的走位里连线转到 **53°** ⇒ 旧判据仍算"交代过了"，不报。
读代码确认：`for event in _crossing_map(context).values(): if event.visible and
event.rotated_deg >= 5.0: bridged = True; break`（命中即 `break`）。

**实测**（`bridging_long11.json`）：`long11` 的连线相对首镜线**最多转了 154°**，
而"看得见的旋转累计"只有 **94.5°**，其中一条可见事件只有 **5.6°**
（`shot_026`）——它却洗白了后面 131–154° 的漂移。⇒ 漏洞是真的。

### F2（**不采纳**）：把有向夹角折成无向 `min(θ, 180−θ)`

它担心"两端对调"会算出 180° 而误报。复核：**这正是该报的情形**——两人对调位置
而观众没看见，就是最经典的越轴；折角会把它折成 0°、直接漏掉。故不采纳，
记在这里以免下次再被同一条说服。
