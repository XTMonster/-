## 2. 三条 P0（这三条决定了"能不能当预演参考"）

### P0-1 环境**一个都没建出来** —— 现象与证据

* 现象：13 张首帧**没有一张**有环境。剧本要的玻璃拱廊、蓝绿铸钢雕花拱顶、彩旗串、干鱼串、
  煤气灯、两侧摊位、远处海面与蒸汽轮船、海雾丁达尔——**全部缺失**；画面只有一块灰色地面 + 灰蓝天。
* 直接证据（跑日志，`blender.log` 的 build 段）：

```
unresolved_anchor: 码头市场拱廊顶棚: relation='覆盖全场上方，蓝绿色铸钢雕花铁艺框架' 解析不出坐标
unresolved_anchor: 拱廊立柱与围栏: relation='沿拱廊两侧纵向排列，伊恩背靠其中一段围栏' 解析不出坐标
unresolved_anchor: 干鱼串与彩旗串: relation='悬挂在拱廊前侧上方，随风摇晃' 解析不出坐标
unresolved_anchor: 糖果摊位:   relation='位于拱廊另一侧，莉莉安娜站在摊位旁' 解析不出坐标
unresolved_anchor: 远处海面与海雾: relation='位于拱廊纵深尽头，画面后方' 解析不出坐标
unresolved_anchor: 地面薄水洼:  relation='散布在拱廊地面低洼处' 解析不出坐标
```

* 根因假设：`SceneBrief.space` 收的是**自然语言的相对关系**，下游只能按闭集解析坐标；
  这六条都是"方位＋氛围"的混合描述（"位于拱廊纵深尽头，画面后方"），
  闭集里没有对应项 ⇒ 解析失败 ⇒ **静默跳过**（只留一条 `unresolved_anchor` 警告）。
* 为什么它是 P0：预演的**第一功能**就是"让下游视频模型看见空间"。没有环境的白模，
  机位/轴线/走位都失去了参照物——后面所有"构图/轴线"判红的可信度也跟着打折。
* 修法（可执行）：
  1. `space` 的 schema 加**可解析方位闭集**（如 `前方/后方/左侧/右侧/上方/脚下` ＋ `距离档`）；
  2. 解析不出来时**报 finding 并把它带回计划**（让模型重写这一条），而不是静默跳过；
  3. 给场景加一个"最小环境骨架"：地面 + 四周遮挡体 + 天空底色（本跑连地面都只有一块大平面）。
* 验收判据：`shot_001` 首帧里**至少能认出三个环境元素**（拱廊拱顶/摊位/海面），
  且 `unresolved_anchor` 数为 **0**。

### P0-2 占位角色 `char_a` / `char_b` **变成了真角色**，且混进多个镜头

* 现象：总览图里几乎每一镜都有一对"绿球+青球"**叠在一起**的方块——它们不是剧本角色。
* 证据链：
  * `shots.json`：`shot_010` 的 `characters = ["char_a","char_b"]`，`axis_pair` 从镜10 起一直是
    `["char_a","char_b"]`（镜10/11/12/13 都在用这一对）；
  * 构建段：`characters: 6`（剧本只有 4 个：米迦尔/伊恩/偷盗者/莉莉安娜）；
  * `label_report.offsets` 里列了 `char_a`、`char_b` 两个标签 ⇒ **白模画面上真的印出了这两个 id**；
  * `script_compliance` 只给了一条 warning：`镜号10 声明的出场角色是米迦尔，计划里却是char_a、char_b（身份错位）`。
* 根因假设：草稿（B1）里模型对"未知角色"用了占位 id，**计划落地时没有做 id→角色名的归一**，
  构建器又把它们当成真角色建了出来（于是多了两个角色、多了一对轴线主体）。
* 修法：计划校验里加一条硬规则——`characters` 必须是角色表里的名字；出现表外 id 就
  **判 error 并重问该镜**（不是 warning）。交付前再加一条产物自检：`shots.json` /
  `label_report` 里不许出现 `char_*` 形状的 id。
* 验收判据：全片 `characters ⊆ {米迦尔,伊恩,偷盗者,莉莉安娜}`；构建段 `characters: 4`。

### P0-3 特写镜头机位过近（"面部特写"变成"眼睛特写"）

* 现象：`shot_002`、`shot_004` 首帧**只有两只眼睛**（占满全画幅）；`shot_007` 也是半张脸。
  三镜声明都是 **CU**，计划也写 CU。
* 证据：`shots.json` 的 shot_002 相机 `position=(-4.879, 0, 1.278)`、`target=(-0.45, 0, 1.428)`、
  `lens=85mm`；构图分 55.5 / 55.7 / 69.9（阈值 70）——**审计判得对，是修不动**（见 §3 P1-1）。
* 根因假设：构图求解按"景别 → 距离"解出的是**头高占比**，但 85mm 长焦 + 该距离下
  实际落到"眼睛特写"档；即"景别档位"与"镜头焦距"的耦合没有被 constrain。
* 修法：把 CU 的定义写成**可测的像素约束**（例如"头顶到下颌占画高 55–75%，且头顶留白 3–10%"），
  求解后用**同一把尺子**回读；不满足就调距离而不是降级。
* 验收判据：CU 镜的"头部占比"落在设定区间内，构图分 ≥ 70。
