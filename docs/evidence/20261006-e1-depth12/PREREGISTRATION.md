# 预登记：深度-12 去标签池的**真判 oracle**（GLM-5.3 裁定点名的唯一终局证据）

> 登记时间 **2026-10-06 22:5x**，**开跑之前**写。产出方＝主线。裁定原件：
> `docs/evidence/20261006-e1-gate-glm/`（GLM-5.3，2026-10-06 22:53，三问裁定）。

## 一、为什么跑这一份（为什么不是别的）

GLM-5.3 的裁定是 **①够不着 ⇒ ②走 (a)：把 RK-13 如实记为"不可达的红"结案**。
它同时指出：若结案前仍要买一份"**无小样本异议**"的终局证据，**唯一值得**的是
**深度-12 去标签池的真判 oracle**——因为现在**唯一的真判上界是 n=8 的单跑（0.375）**，
而 64 条那份是 **proxy**（绝对值不许当读数）。裁定给的可证伪判据原话：

> **oracle ≥ 0.703125 ⇒ 撤销 (a) 转 (c)**；**oracle < 0.703125 ⇒ (a) 终局**。

它原本还给了"**零成本前置检验**"（先验"行分与三元组语境无关"，成立才敢把
`16 查询 × 12 来源 = 192 行` 拼成 3,520 个三元组的 oracle）。**该前置检验实测失败**：
同一查询内同一来源在 C(5,2)=10 个三元组里的分 **41/48 对不一致**
（`docs/evidence/20261006-e1-gate-glm/row_context_check.json`）
⇒ **行分不能拼**，只能**整组判** ⇒ 成本从"192 行"涨到 **3,520 次三元组判分（每次两位评委）**。

## 二、预登记的设计（开跑前定死，跑完不许改）

| 项 | 值 |
|---|---|
| 仪器 | `tools/knowledge/e1_labelfree_pool.py`（**冻结清单第 4 件**，`--pool` 已参数化） |
| 池子 | 产品检索器 `CaseIndex.retrieve(query, top_k=12)` 的**原始名次**（不读任何判分字段） |
| 三元组 | 该池子的**全部组合 C(12,3) = 220 组/查询**（不抽样、不挑） |
| 查询 | `docs/evidence/20261006-c3-deep-pool/reviews.current.batch3.top120.jsonl` 的**前 16 条**（文件序，先声明） |
| 判分 | 与 `e1_panel` **逐字同一份**：同 SYSTEM、同两位评委（`deepseek-chat`＋`glm-5.3`）、同 C=3 语境、P14-249"少一位评委不发分" |
| 相关 | 两位评委均值 **≥ 4.0**；少一位评委的行**留在分母、不算相关** |
| 判据（读到什么算什么） | **oracle ≥ 0.703125 ⇒ 撤销 (a)**；**< 0.703125 ⇒ (a) 终局**（照裁定原话） |
| 成本 | 16 × 220 = **3,520 组** × 2 评委；按 `--workers 6` 与既有速率，量级 **3.5～7 小时** |
| 先决 | ① 开跑前**握手**（`e1_panel.preflight`，P14-291）必须通过；② 等 pid 57312（深度-6、64 条）跑完再开，避免抢通道 |

**预先说清的边界（不许事后补）**：

1. 这份测的是**深度 12**，**不是**"任何深度"。深度 20 的 proxy 上界是 0.6563、
   深度 40 是 0.8125——**它们没有被这次真判覆盖**，所以即使 `< 0.703125`，
   能写下的结论是"**深度 12 处，去标签池的真判 oracle 低于门槛**，
   更深池子仍只有 proxy 证据"。**不许**把它写成"任何去标签池都够不着"。
2. proxy 在深度 6 上**低估**过真判（proxy 0.3125 vs 真判 0.375，+0.06）。
   所以本次的预期值是 **proxy 0.5365 上下浮动**，**不是**照抄 proxy。
3. 16 条查询是**文件序前 16 条**，不是分层样本；n=16 的 95% 区间很宽，
   结论只能按"是否跨过 0.703125 这条线"读，不许当作精确估计。
4. 判分**不重跑第二遍**（除非通道抖动导致 `unscored_rows` 异常）；
   若 `unscored_rows == triples_judged`（全没判到）⇒ 判**仪器故障**，产物作废重跑。

## 三、开跑与落地

```powershell

    --queries docs/evidence/20261006-c3-deep-pool/reviews.current.batch3.top120.jsonl `

```
