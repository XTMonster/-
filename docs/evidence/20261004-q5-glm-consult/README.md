## 新增的可核对测量：子集过滤门到底还剩几条

GLM 的 F4(a) 是个**能算**的问题，所以直接算（口径与 `tests/test_q5_run_join.py`
的三分类一字不差：`q` 里 `运镜` 那一项**不点名**被量的字段才算数）：

```
带 expect_movements 的条目           105
其中 q 不带 "运镜"（过滤后可用的）     8   hq_1809 hq_1810 hq_1819 hq_1877 …
§4.1b 要求的夹具下界                 ≥30
⇒ 8 < 30：过滤式子集门在现在的语料上**撑不起下界**
```

这条数字**已经被用例钉住**（`tests/test_q5_run_join.py::test_the_shipped_movement_entries_decompose_into_tautological_and_usable`
断言 `(86, 11, 8)` 且 `discriminating + predictive >= 18`），所以它不是"我刚跑出来的孤证"。

**结论**：F4(a) 提得对、算下来不可行；②（重标入口形状，让 `q` 不点名被量字段）
不是"更贵的等价方案"，而是**唯一能同时满足下界与鉴别力的方案**。
