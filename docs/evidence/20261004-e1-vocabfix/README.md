## 噪声底（3 次重复，**判据与门限一个字没动**）

glm-5.3 会诊的 F3 说"17/192 对 23/192 只有约 1 个标准误"。按它的话跑了噪声底：
同一份语料、同一批 64 条查询、同一面板，A/B **交替**各跑 3 次（每次 192 条判分）：

| 臂 | 三次读数 | 合并 |
|---|---|---|
| A（旧提示词，739 条线索） | 0.0938 / 0.0833 / 0.0990 | **53/576 = 0.0920** |
| B（词表同源，363 条线索） | 0.1146 / 0.1302 / 0.1146 | **69/576 = 0.1198** |

* 池化检验：**z = 1.53**，差 +0.0278，95% CI ≈ [-0.0078, +0.0633] ⇒ **没到 5% 显著**
  （会诊的提醒成立）。
* 按查询配对（各臂三次取最高分）：B 好 **35** / 差 **14** / 平 15（n=64），
  符号检验 p ≈ 0.004 ⇒ **方向是稳的**。
* 两个读数的意思：**"词表对齐确实在起作用，但幅度只有 +0.03 量级"**——离 0.70
  还差 5 倍以上。原始读数在 `noise_floor.json`。

## 这一次量到了什么

同一部片子、同一批 64 条逐镜中文查询、同一份 810 条案例语料，**只改生成线索时
给模型的那份闭集词表**（从提示词里手写的一小串，换成
`tools/kb_fetch/vocabulary.py` 的真源派生）：

| | A：旧提示词 | B：词表同源 |
|---|---|---|
| 线索条数 | 739/810 | **363/810** |
| 查询点名却在整库线索里找不到的工艺词 | 153/309 = 49.5% | **104/309 = 33.7%** |
| E1（跨族面板，64 查询 × top-3） | 17/192 = 0.0885 | **23/192 = 0.1198** |
| 一条 ≥4 都没有的查询 | 47/64 | 42/64 |

两个独立读数同向（缺口少 49 处、E1 多 6 条），但**样本量不足**（见上）。
`reviews.jsonl` = B 臂那一次。
