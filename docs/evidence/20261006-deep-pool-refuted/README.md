## 读数说明什么

1. **"数出来的上限"涨得很猛**（0.84 → 0.97）——更深的池子里确实还有相关案例
   （按检索名次分档，rank 49–128 的相关率仍有 0.025～0.048，**没有归零**）。
2. **但"可达值"几乎没动**（**0.4583 → 0.4740，只 +0.0157**）。
   ⇒ **挖得再深也没用**：那 3 条"最好的"放进真实判分语境，照样只有约一半被判相关。
3. ⇒ **卡点在判分语义，不在候选池**。

1. **当前测量协议下，E1 的可达上界约 0.46～0.47**（不随池子深度变）。

   **它没得可挖了**（先前"只拿到上限 52%"是**拿错分母**）。
