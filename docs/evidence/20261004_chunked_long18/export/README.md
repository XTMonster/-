## 怎么用

1. 取 `blockout_<shot>.mp4` 作为**参考视频**（结构 / 机位 / 节奏）；
2. 取 `first_frames/<shot>.png` 作为**输入图**（图生视频）；
3. 取 `prompts.md` 里对应镜头的 Prompt 作为**提示词**。

> 参考视频里带白字黑描边的角色标签，便于审阅；`first_frames/` 与 depth 序列**刻意不带标签**，避免标签被下游视频模型当成画面内容学走。
5. `blockout_full.mp4` 是各镜按顺序接成的全片，适合一次性喂给视频模型。
