# D1b 躯干形状 A/B（§7 唯一一项待用户拍板）

文档 §7 只剩这一项：**D1b 躯干形状——① 保持圆柱（现实现）／② 圆角方体（更接近参考图的"块面感"）**，
裁决方式是"**P10 内以 A/B 截图裁决**"。这一目录就是那张 A/B。

## 两张图（先看这两张）

| | 文件 | 形状 |
|---|---|---|
| **A（现状）** | `A_cylinder.png` | `primitive_cylinder_add(radius=0.25, depth=0.748)` |
| **B（候选）** | `B_rounded_box.png` | 等外接盒的圆角方体（cube ＋ Bevel，倒角 = 0.25 × 半径） |

两张都是**同一条工厂路径**建出来的角色（层级、枢轴、材质、锚点全一样），
**同一个机位**（`place_camera_for_shot(shot_type="MS", side="front")`，也就是产品会给这一镜的机位），
Workbench **STUDIO 受光**。

> **为什么这一支用受光而不是其他探针的 FLAT**（实测）：FLAT 让所有面拿到同一个颜色，
> 方体与圆柱**除了轮廓四角几乎一模一样**（差分只有 0.55% 的画面），人看不出该看的东西。
> 受光之后圆柱是连续渐变、方体是**分明的面与棱**——这才是要裁的那件事。

另有 `A_CU_left.png` / `B_CU_left.png`：同一对的**侧向近景**，用来看肩膀与胸廓的转折。

## 机器部分量到的三件事（都不是"好不好看"）

探针 `tools/blender_tests/test_character_body_ab.py`（已登记进 `tools/run_tests.ps1`）：

```
① 外接盒：A (0.5, 0.5, 0.748)  vs  B (0.5, 0.5, 0.748)   max_delta = 0.0
   ⇒ 换形状**不需要**动 bbox / 构图常量（文档担心"选项 ② 需改 bbox/构图常量"——
     实测不成立：等外接盒建出来的圆角方体与圆柱同盒）
② 锚点：head_center_z 1.3855、label_anchor_z 2.0 —— 两种形状**逐位相同**
   ⇒ 骨架、取景、标签锚都不受影响
③ 剪影/明暗确实不同：MS/front 差分 10194 px（4.42% 画面）、CU/left 12739 px（5.53%）
   下界 460 px、上界 69120 px 都远离 ⇒ 既"看得出不同"又"还是同一个主体"
```

## 这一项要你做的

看 `A_cylinder.png` 与 `B_rounded_box.png` 两张图，选 ① 或 ②。

* 选 ①（圆柱）：**什么都不用改**，这一项就此冻结。
* 选 ②（圆角方体）：改动面已经量清楚——`character_factory.py` 的
  `primitive_cylinder_add(...)` 换成 cube ＋ Bevel（同外接盒），
  倒角比例是个可调参数（这里取 0.25 × 半径）；**bbox/构图常量不需要动**。

**未经你裁决之前，仓库里的生产几何保持 ①**（这一支探针只在**探针场景**里建 B，
不碰 `character_factory` 的默认路径）。
