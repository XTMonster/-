## 代理 0.5625 与真实 0.3542 的差距：**又是"尺子"那件事**（要单独记账）

代理量的是"模型挑的 3 条**在它们原来的三元组里**是不是被标过相关"；真实 E1 是
"把模型挑的这 3 条**当成一个新的三元组**重新判分"。而本仓**已实测**过评委的给分**随同批候选变化**
（`docs/evidence/20261006-e1-judge-context/`：同检索、同内容，只因调用里塞的候选条数不同，
两位评委同向漂移 0.18→0.32）。⇒ **代理系统性偏乐观**，**不能拿它当 E1 用**。

## 三个对照组跑完了（**同一批 16 条留出查询**，官方口径）——微调**还没赢过 LLM 重排**

| 方法 | 文件 | E1（16 查询 / 48 行） |

| **微调 cross-encoder** | `reviews.ft.heldout16.rep1.jsonl` | **0.3542**（17/48） |

⇒ 结论要**照实说**：**微调把零样本抬了 9 倍（代理口径），但按真实 E1 仍输给 LLM 重排**

**为什么代理会骗人（这条是方法论收获）**：代理 0.5625 > 真实 0.3542，
而 LLM 重排真实 0.50；代理奖励的是"挑出**在原三元组里**被标过相关的行"，
比"挑出**新三元组里**评委仍会叫相关的行"容易得多——**又是"尺子"那件事**。
