## 极差为什么过不去（这不是缺陷，是上游约束）

`kimi-k3` **只接受 `temperature=1`**（传 0 直接 `HTTP 400`）。于是**重排器自己就是随机的**——
同一查询三次可能返回不同的 3 条，评委又各自有 ±0.5 的抖动，两个随机源叠起来就是 0.04。
第三方（Kimi K3）自己给的判词里写着这条路：「**Kimi 强制 temperature=1 ⇒ 噪声不能调没，
只能重复取样压掉**；入链必须取中位」。所以本目录的做法就是它的处方：
**报中位数、把极差一起报**，而不是假装 0.02 那条线还在。
