# §77.3 的开放问题结案：锚口径多报的那些镜头，**画面判据证实的只有 2 条**

§七十七 把"轴线漂移改按**上一个已交代的锚**量"实现出来又回退，理由写在当时那一节：
三份冻结工程的 R001 由 13、40、7 变成 33、41、26，而**没有独立判据**证实多出来的是
真越轴。这一页把"没有独立判据"补成**有**：给每一镜同时算三个量，再看多报的那些
镜头有没有画面上的证据。

## 怎么算的（`corroborate_probe.py`，零 LLM）

* **现行口径**：角度相对**规范首镜线**，桥接 = 本镜机位中性 或 **全片**可见旋转累计
  覆盖漂移；
* **锚口径**：`cinema/axis.drift_report`（纯函数）——一次被交代过去的重建**重新起锚**，
  之后的漂移相对新锚量；
* **独立判据**：`_screen_polarity_flip`——把两人投影到屏幕，看**相邻两人镜**的左右序
  有没有在没人看见时翻转。它**既不读首镜线、也不读锚**，所以可以拿来投票。

```
blender --background --factory-startup --python \
    docs/evidence/20261004-r001-anchor/corroborate_probe.py -- \
    --project docs/evidence/<run>/project --out docs/evidence/20261004-r001-anchor/<run>.json
```

## 结果

| 工程 | 锚口径多报的 R001 | 其中**画面判据证实**的 | 其中至少两人同框的 |
|---|---|---|---|
| long9 | **22** | **0** | 9 |
| long11 | 1 | 0 | 1 |
| long12 | **19** | **2** | 9 |
| 合计 | **42** | **2** | 19 |

换参照系换来的 42 条"越轴"里，画面判据只认 2 条。⇒ **§七十七 的回退是对的**：
那条路现在报出来的多半是噪声，不是更准的判据。判据一个字不改。

## 两个口径本身的差异（顺带量到的）

* `error_now` 在 long9/long12 上是 **0**——因为现行口径的桥接用的是"全片可见旋转
  累计"（long9 实测 278.9°），它**宽松**；锚口径把参照系统一之后立刻严厉起来，
  这是两边的真实差别，不是 bug；
* long11 的探针只覆盖了 **42/64** 镜（`shots_without_report` 列了 22 个）：
  那条轴线由**第一个两人镜**确立，之前的镜头没有配对连线可比——这一点在两种口径下
  都一样，不影响上面的对照（两边用的是同一批可算镜头）。

## 这一页留下了什么

1. `corroborate_probe.py`——**给任何"要不要换判据"的问题准备的投票器**：先量
   新旧两套判据的分歧，再拿一条**不读被测实现**的画面量去证实。§七十三 的 F1
   回退当时是手动算的，现在有现成工具；
2. 三个工程的逐镜 json（`angle_now`/`bridged_now`/`error_now`/`angle_anchor`/
   `bridged_anchor`/`error_anchor`/`acknowledged`/`screen_flip`/`both_on_screen`）。
