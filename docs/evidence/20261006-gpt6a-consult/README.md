# GPT-6A 难题攻关（单侧）：**用原评委的标签微调一个交叉编码重排器**

日期 2026-10-06 07:34。通道：中转站 `gpt-6-astra`，`reasoning_effort=max`
（`work/_gpt6a_ask.py` → `tools/relay_consult.py::consult`；prompt 338 token、
completion 4,943 token、墙钟 233.4 s，其中**第一次尝试被 Cloudflare 524 掐掉**、第二次成功）。

## 它给的方案（逐字见 `e1_gap_answer.md`）

1. **做法**：固定 50 条候选，用**原两位评委的标签**（均分 ≥4 ＝ 正例）**微调预训练交叉编码重排器**；
   输入是"分镜需求 ＋ 案例正文"；把"现模型排前却不相关"的当**难负例**；
   **按分镜任务隔离训练与测试**，输出前三。
2. **为什么可能有效**：新增的是**对齐原判据的监督信号**——让它学会区分"语义相似"与
   "真正有参考价值"，而**不是继续赌提示词**。
3. **可证伪判据**：先锁死训练预算；另取 **100 个未见分镜**由原评委盲评前三；
   **原口径相关率 <0.70 即本轮失败**，并同时报按分镜重采样的 **95% 置信区间**。

## 未做 / 风险（如实挂）

* **训练本身没跑**（本目录只是判词）。它的第三点要求"另取 100 个未见分镜"——
  这一步**必须**先做，否则验收会被"训练/测试同源"污染。
* **标签噪声**：训练标签来自那两位评委，而它们**在同一批行上差 0.27**（P2）。
  用有分歧的标签训，可能把分歧也学进去 ⇒ 训练前该先按 P2 把评委判据对齐一次。
* 16 GB 显存训 cross-encoder 的**批次上限未测**；训练集 3,072 行对 cross-encoder 偏小
  （容易过拟合，需要按分镜隔离 + 早停）。
