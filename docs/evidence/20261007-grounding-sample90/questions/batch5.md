找到取值本身**。现在要分清这 1,262 条"未被来源佐证"里，各有多少属于下面三类——

**只输出一个 JSON 数组**，长度 = 8，每条形如
`{"i": 1, "class": "hidden"|"wrong_card"|"wrong_value", "why": "<不超过 20 字>"}`。
