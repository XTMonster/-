# P14-74：R001 换代（v1.9）——判据从"机位 vs 冻结线"换成三件**可观测量**

用户 2026-10-04 的追问：**"会诊 ai 有先看目前落实的情况与源码么？了解项目才能提出
想法"**。有——但**要按它的包线喂**。这一轮把源码**逐字**摘要成 ≤3.3k prompt token
的 bundle 才问得动（详见下），它给出的关键更正直接改了实现。

## 会诊给的两条更正（源码在手时才有）

1. **`flip = rotated_deg ≥ 90°` 是错的**：它说"换边 ⇔ 本镜机位相对 A→B 连线的
   **叉积符号**镜内变号，与转角无关——30° 可换、170° 可不换"。也就是说、
   **左右序由"机位在连线哪一侧"唯一决定**，把"连线转了多少度"当换边判据会漏/误报。
   ⇒ 规则侧因此**直接量机位相对当前连线的侧向符号**（下面第 ② 条）。
2. **`axis_state` 的 `side` 是隐藏状态**："flip 历史的累积积分，单帧重放不出"。
   ⇒ 所以它必须由**纯函数**从位置流推出（`axis_state` 就是），并且规则要另有一条
   **独立于构建器**的内容——即下面第 ③ 条。

## v1.9 的 R001 = 三件可观测量

| # | 判据 | 量什么 | 抓什么 |
|---|---|---|---|
| ① | **相机相对当前连线的侧向符号** | 机位 xy 与**当前**两人连线（`current_line`） | 机位自己摆错：求解器兜底、修复工具挪机位、用户手改（`test_phase4_repair` 的 `setup_camera_fixes_the_violation` 就是它） |
| ② | **轴线被走位重建却没被拍出来** | **规范首镜线** vs **当前派生线**的夹角 ≥30°，且没有合法桥接 | `long12` 那 26 条"整场挪到布景另一处、线跟着转" |
| ③ | **中性机位**（落在连线上） | `check_camera_neutral` | 只报警告——§6.2 的"合法跨轴桥梁" |

合法桥接（把 ② 降级为**警告**）：**看得见的换位**（`crossing_events.visible` 且
`rotated_deg ≥ 5°`）或**本镜机位中性**。
