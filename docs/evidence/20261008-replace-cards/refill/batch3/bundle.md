# 会诊包（实际送进模型的逐字内容）

## system（角色：标注）：本次**没有** system 提示词（`--plain` 机械标注包，问题自带输出契约）

## user（所有角色共用；角色 标注 的包逐字如下）

```text
# 本次要审的问题

# 给下面每张卡各写一条**检索期望**（oracle 条目）

背景：知识索引刚做过一次"清洗式重抽取"（把一批卡的原子边重抽了一遍），
有几张卡因此没有条目了。请**按卡正文**为它们各写一条。

**只输出一个 JSON 数组**，每个元素形如：

```
{"from_card": "<卡 id>",
 "q": "<查询串：用中文查询键写，形如 动作=后退；强度=mid>",
 "must": ["<边写法：TYPE:槽位=取值,槽位=取值>"],
 "top1": ["<与 must 同一条>"],
 "why": "<不超过 30 字：正文的哪句话支持这条>"}
```

边界（照抄，别自由发挥）：

1. `must`/`top1` 的**边类型与取值**必须逐字取自下面"这张卡当前在索引里支持的耦合"；
2. 挑的那一条必须是**卡正文真的支持**的；正文都不太支持时挑最接近的，并在 `why` 里写清；
3. `q` 的键只能取：情绪/动作/运镜/景别/镜头/节奏/特效/音效/机位/光线/构图/轴线/题材/
   桥段/意图/对白/语气/配乐/道具/转场/强度/镜长；没有查询键的槽位（`headroom_policy`/
   `pair`/`axis_side`）**不要写进 q**；取值逐字相同；
4. 长度 = 下面卡的张数，顺序一致。不要任何额外说明。

---

### 卡片 gen_cine_0007（domain=cinematography）标题：聚光镜尺寸宁大勿小
正文：为给定底片选配聚光镜时，应选直径足够大的型号，避免因聚光镜过小造成底片边缘受光不足。
关键词：受光
这张卡当前在索引里支持的耦合（选**一条**）：
  - LIGHT_PACK:lighting=高调,intensity=mid

### 卡片 gen_cine_0010（domain=cinematography）标题：缩小复制无皮腔难题
正文：从大原稿翻拍小尺寸复制品时，皮腔延伸不足的问题不会出现；只有等大或放大复制才需要两倍焦距的延伸量。
关键词：放大倍率
这张卡当前在索引里支持的耦合（选**一条**）：
  - PROP_PACK:prop=陈设,shot_size=MS,camera_angle=平视

### 卡片 gen_cine_0013（domain=cinematography）标题：光圈环六档刻度
正文：光圈环旋转行程分为六个固定刻度，对应 f/3.5、f/4、f/5.6、f/8、f/11、f/16，孔径从约 3/5 英寸递减到 1/8 英寸，可微调以适应任意光线。
关键词：f值
这张卡当前在索引里支持的耦合（选**一条**）：
  - LIGHT_PACK:lighting=正面光,intensity=mid

### 卡片 gen_cine_0018（domain=cinematography）标题：用表格确定镜头距离
正文：可查表确定给定放大倍率下镜头到底片和屏幕的距离，该表覆盖常规需求，可用于搭建放大设备。
关键词：距离表、放大倍率
这张卡当前在索引里支持的耦合（选**一条**）：
  - STAGING_PACK:composition_rule=framing,shot_size=MS,camera_angle=平视

### 卡片 gen_cine_0019（domain=cinematography）标题：酸停浴抑制渗色
正文：可用酸性停浴或在染浴中加酸来改变渗色，但渗色本质上是染料自身属性，选料时仍应以低渗色为准则。
关键词：染料属性
这张卡当前在索引里支持的耦合（选**一条**）：
  - LIGHT_PACK:lighting=冷光,intensity=low

### 卡片 gen_comp_0264（domain=composition）标题：斜面用两线定位
正文：确定一个斜面的空间位置，只需在面内取两条线：一条水平线 AB 与一条与之垂直的最陡线 CD；面内平行 AB 的线皆水平，平行 CD 的线皆最陡。
关键词：最陡线、水平线
这张卡当前在索引里支持的耦合（选**一条**）：
  - STAGING_PACK:composition_rule=balance,shot_size=MS,camera_angle=平视

### 卡片 gen_prod_0161（domain=production）标题：旋转镜头加滤色片
正文：尝试彩色活动影像时，可用带滤色片的旋转镜头方案；但该做法在当时并未成功，仅作历史参考。
关键词：彩色
这张卡当前在索引里支持的耦合（选**一条**）：
  - EDIT_RHYTHM:pacing=short,avg_shot_len=<1s
```
